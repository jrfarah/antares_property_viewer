# ANTARES Properties Browser

A fast, searchable reference for all ANTARES Locus and Alert properties —
hostable as a static GitHub Pages site.

## Files

| File | Purpose |
|------|---------|
| `antares-properties.html` | The browser UI — loads `properties.json` at startup |
| `properties.json` | Pre-fetched property data (generated by the scraper) |
| `scrape_antares.py` | Script to regenerate `properties.json` from the ANTARES API |

---

## Quick start

### 1. Generate `properties.json`

Run the scraper **once** on your local machine (requires network access to
`api.antares.noirlab.edu`):

```bash
pip install requests          # only dependency
python scrape_antares.py
```

This writes `properties.json` to the current directory and prints a summary:

```
✓ Wrote 267 locus + 183 alert properties
  → /path/to/properties.json
```

### 2. Preview locally

Browsers block `fetch()` on `file://` URLs, so use a tiny local server:

```bash
python -m http.server 8000
# open http://localhost:8000/antares-properties.html
```

### 3. Deploy to GitHub Pages

```bash
# From your repo root (all three files in the same directory):
git add antares-properties.html properties.json scrape_antares.py README.md
git commit -m "Add ANTARES properties browser"
git push

# Enable GitHub Pages in repo Settings → Pages → Deploy from branch → main / (root)
```

Your browser will be live at `https://<you>.github.io/<repo>/antares-properties.html`
(or at the root if you rename the HTML to `index.html`).

---

## Refreshing the data

When the ANTARES team adds new properties, just re-run the scraper and
commit the updated `properties.json`:

```bash
python scrape_antares.py
git add properties.json
git commit -m "Refresh ANTARES properties $(date +%Y-%m-%d)"
git push
```

## Features

- **Real-time search** across name, description, origin, and type
- **Locus / Alert tabs** with entry counts
- **Filter chips** for data type (`int`, `float`, `str`, `bool`) and origin (`ANTARES`, `ZTF`, …)
- **Sortable columns** — click any header; click again to reverse
- **Highlighted matches** in search results
- Press `/` to jump to the search box from anywhere on the page
- No build step, no dependencies beyond vanilla JS + Google Fonts
